# Пример сеанса

Сеанс `python -m mathtutor practice -n 5`. Ответы «ученика» подставлял скрипт (`scripts/make_docs.py`), чтобы сеанс был воспроизводимым. Всё остальное (выбор тем, сложность, диагностика, подсказки, решение) — настоящий вывод программы.

```
Команды: h — подсказка, s — показать решение, q — выйти. Ответы пишите обычным текстом.

Задача 1/5  [Свойства бинарных отношений, сложность 1, освоение 20%]
Дано множество и отношение на нём: A = {1, 2, 3}, R = {(1, 2), (2, 2), (2, 3)}.
Какие свойства выполняются? Введите номера через пробел: 1 — рефлексивность, 2 — симметричность, 3 — антисимметричность, 4 — транзитивность. Если не выполняется ни одно, введите 0.
> 1 3
Неверно.
Похоже на типичную ошибку: рефлексивность требует пары (a, a) для КАЖДОГО элемента множества, а не для некоторых.
Рефлексивность: вы считаете, что она выполняется, но это не так: в отношении нет пары (1, 1).
Попробуйте ещё раз (попытка 2 из 3).
> 3
Верно! Решено не с первой попытки или с подсказкой, поэтому в оценку освоения это пойдёт как неуверенный результат.

Задача 2/5  [Свойства бинарных отношений, сложность 1, освоение 18%]
Дано множество и отношение на нём: A = {1, 2, 3}, R = {(2, 2)}.
Какие свойства выполняются? Введите номера через пробел: 1 — рефлексивность, 2 — симметричность, 3 — антисимметричность, 4 — транзитивность. Если не выполняется ни одно, введите 0.
> h
Подсказка 1/3: Выпишите определения четырёх свойств и проверяйте каждое отдельно.
> h
Подсказка 2/3: Для каждого свойства ищите контрпример: свойство выполняется, только если контрпримера нет.
> 2 3 4
Верно! Решено не с первой попытки или с подсказкой, поэтому в оценку освоения это пойдёт как неуверенный результат.

Задача 3/5  [Комбинаторика, сложность 1, освоение 20%]
В конкурсе участвуют 8 человек. Сколькими способами можно распределить призовые места с 1-го по 4-е (все призёры разные)?
> 1680
Верно!

Задача 4/5  [Свойства бинарных отношений, сложность 1, освоение 17%]
Дано множество и отношение на нём: A = {1, 2, 3}, R = {(1, 1), (1, 2), (1, 3), (2, 2), (2, 3), (3, 1), (3, 2), (3, 3)}.
Какие свойства выполняются? Введите номера через пробел: 1 — рефлексивность, 2 — симметричность, 3 — антисимметричность, 4 — транзитивность. Если не выполняется ни одно, введите 0.
> s
Правильный ответ: 1 (рефлексивность)
Рефлексивность: выполняется.
Симметричность: не выполняется (есть пара (1, 2), но нет пары (2, 1)).
Антисимметричность: не выполняется (есть обе пары (1, 3) и (3, 1) при 1 ≠ 3).
Транзитивность: не выполняется (есть пары (2, 3) и (3, 1), но нет пары (2, 1)).

Задача 5/5  [Определитель матрицы, сложность 1, освоение 20%]
Вычислите определитель матрицы:
[ -5   6 ]
[  0  -4 ]
> 20
Верно!
```
