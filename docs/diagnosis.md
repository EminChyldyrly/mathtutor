# Примеры диагностики ошибок

Каждый неверный ответ ниже получен по конкретному «неверному правилу» (типичной ошибке); программа определяет его по значению ответа и объясняет. Файл сгенерирован `scripts/make_docs.py` запуском настоящих команд.

## Определитель: перепутан знак

```
$ python -m mathtutor task det --difficulty 2 --seed 1
Вычислите определитель матрицы:
[  1   6  -4 ]
[  6  -1  -3 ]
[ -1  -4  -1 ]

$ python -m mathtutor check det --difficulty 2 --seed 1 -143
Неверно.
Похоже на типичную ошибку: знак результата противоположный; проверьте порядок вычитания (главная диагональ минус побочная, а не наоборот).
(код возврата 1)
```

## Определитель 3×3: знаки в разложении по строке

```
$ python -m mathtutor task det --difficulty 2 --seed 3
Вычислите определитель матрицы:
[  5  -3  -2 ]
[  0  -2  -3 ]
[  5  -4   5 ]

$ python -m mathtutor check det --difficulty 2 --seed 3 -175
Неверно.
Похоже на типичную ошибку: при разложении по строке знаки должны чередоваться (+ − +), а вы их не меняли.
(код возврата 1)
```

## Система: значения перепутаны местами

```
$ python -m mathtutor task system --difficulty 2 --seed 3
Решите систему уравнений:
−x + 4y − z = 17
−2x − 3y − z = −20
x + z = 3
Ответ запишите как x, y, z (например: 1, 1, 1).

$ python -m mathtutor check system --difficulty 2 --seed 3 '(5, 2, 1)'
Неверно.
Похоже на типичную ошибку: значения x и y перепутаны местами.
Проверка подстановкой:
Подстановка в уравнение 1 (−x + 4y − z = 17) даёт 2 вместо 17, так что уравнение не выполняется.
Подстановка в уравнение 2 (−2x − 3y − z = −20) даёт −17 вместо −20, так что уравнение не выполняется.
Подстановка в уравнение 3 (x + z = 3) даёт 6 вместо 3, так что уравнение не выполняется.
(код возврата 1)
```

## Комбинаторика: учтён порядок

```
$ python -m mathtutor task comb --difficulty 1 --seed 4
Из 9 кандидатов нужно выбрать комиссию из 2 человек. Порядок в комиссии не важен. Сколько существует способов?

$ python -m mathtutor check comb --difficulty 1 --seed 4 72
Неверно.
Похоже на типичную ошибку: вы посчитали размещения (порядок учтён), а нужны сочетания: комиссия из тех же людей в другом порядке — та же комиссия.
(код возврата 1)
```

## Отношения: транзитивность проверена не полностью

```
$ python -m mathtutor task rel --difficulty 1 --seed 18
Дано множество и отношение на нём: A = {1, 2, 3}, R = {(1, 1), (2, 2), (2, 3), (3, 2)}.
Какие свойства выполняются? Введите номера через пробел: 1 — рефлексивность, 2 — симметричность, 3 — антисимметричность, 4 — транзитивность. Если не выполняется ни одно, введите 0.

$ python -m mathtutor check rel --difficulty 1 --seed 18 '2 4'
Неверно.
Похоже на типичную ошибку: в проверке транзитивности нужно рассматривать и случаи, когда элементы совпадают: из (a, b), (b, a) следует (a, a).
Транзитивность: вы считаете, что она выполняется, но это не так: есть пары (3, 2) и (2, 3), но нет пары (3, 3).
(код возврата 1)
```
